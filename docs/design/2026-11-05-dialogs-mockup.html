Вопросы агента и разрешения: панель на месте строки ввода

Пока агент ждёт ответа, строка ввода уступает место панели той же ширины и формы. Заголовок, предмет (команда или вопрос), нумерованный список вариантов, подсказка по клавишам. После ответа панель закрывается, а в ленте остаётся одна строка с итогом.

Тёмная тема Dark+, переменные VS Code с запасными значениями. Окна по 900 px, два последних кадра по 420 px.
